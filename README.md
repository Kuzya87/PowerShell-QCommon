# PowerShell-QCommon

Базовый модуль для общих вспомогательных функций и классов, которые используются
в других модулях PowerShell.

Требуется PowerShell 7.6 или новее.

## Структура

- `Classes/` — определения публичных классов и перечислений (`*.ps1`).
- `functions/` — публичные функции (`*.ps1`).
- `Private/Classes/` — определения внутренних классов (`*.ps1`).
- `Private/Functions/` — внутренние функции (`*.ps1`), не предназначенные для экспорта.
- `Root.psm1` — загрузчик файлов из этих каталогов.
- `PowerShell-QCommon.psd1` — manifest модуля и список экспортируемых команд.

Файлы в каждом каталоге загружаются в алфавитном порядке: сначала внутренние
классы, затем публичные классы, внутренние функции и публичные функции.
Для классов и перечислений из `Classes/` загрузчик автоматически регистрирует
type accelerators по имени типа и удаляет их при выгрузке модуля. Типы из
`Private/Classes/` не регистрируются. Публичные функции нужно явно перечислять
в `FunctionsToExport` в manifest.

## Использование

```powershell
Import-Module .\PowerShell-QCommon.psd1
```
